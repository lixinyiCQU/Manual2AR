## 2026-11-02 打印板检查修复

- 日志中两类字段拼写错误导致有效异常观察整份失效：`bbox_0_0_1000` 与 `target_point_0_000`。新增有限字段名规范化，包括“正确字段＋拼错的空字段”；原始响应不修改，修复另行记账。两份非空坐标冲突、未知字段和非法几何仍拒绝，校验重试明确列出字段错误。
- 为 VLM 增加文件配置 `vlm.proxy_mode`（auto/system/direct）。auto 仅在本机回环代理不可连接时尝试直连，保留 TLS 验证，不修改系统环境；远程代理策略不自动绕过。GPU 客户端同样识别失效本机代理，但不会切换模型或伪造成功。
- 视觉请求失败通过枚举区分连接、超时、凭据、限流和回复校验；Unity 显示对应的简短操作建议，不展示模型原文或原始异常。分割不可用时保留已检测异物结论。
- 斜视角 Prompt 明确接受梯形、相机旋转和非水平边，使用实际板面轮廓而非矩形外包框判断位置；遮挡、裁切、看不清的区域仍不视为干净。
- 已知异物移除判断优先使用当前帧板面掩码的凸包及目标掩码，保留空洞内部和仍接触板面的目标；只有明确脱离支撑范围才记录移除。板面丢失、掩码缺失或截断不能证明移除。规则版本 `plate-surface-v1.0.1`。

现场验证：使用失败会话保存的斜拍原图，真实千问调用约 13.1 秒识别出橙色带孔物体；本地 OpenCV 成功分割打印板和异物。历史模型回复共 25 份，经过有限字段规范化后均通过原严格 Schema，其中 19 份需要字段名修复；这只证明结构可读取，不表示内容均正确。证据位于项目外 `Manual2AR-Data/runs/integrated/validation/inspection-fix-20261102-162624/`。

用户要求本轮暂不测试 GPU 连接；不据此声称真实 GPU 跟踪已恢复。
