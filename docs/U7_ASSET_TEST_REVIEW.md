# U7 视觉资产测试审计与更新

审计对象：`References/3DAssets Test.mp4`、实测空间会话 `79fa245622cf44039398d0d3670d1012`、运行中的后端与 Windows 缓存客户端。测试记录与源文件、视频留在项目外，不提交密钥、录屏或现场图。

## 已确认的问题

1. **客户端混用了旧版本。** 录屏用的 `%LOCALAPPDATA%/Manual2AR/Desktop/Manual2AR_Data/Managed/Assembly-CSharp.dll` 与上一阶段客户端相同，和资产库版本不同。其交付清单也指向 `Manual2AR-Spatial-Guidance`，没有资产库描述。Unity 的 EXE 启动壳哈希相同，不能据此认为客户端相同。后端实测事件中已经发出 U7 新 `presentation`；旧客户端没有绘制组合模型。
2. **旧定位语义错误。** 原 Prompt 把立柱上的双螺丝底座写成白色件，并按当前单颗螺丝找位置。日志中模型反而认为真实灰色底座不符合要求；其现场照片里也没有独立白色支架。
3. **旧检查条件与照片能力不符。** 拍照参考要求判断螺丝是否拧紧、接合面是否完全贴合，造成正确安装外观也返回不确定。
4. **缺少可调朝向和 XYZ。** 两个作用点仅确定一根轴，不能恢复完整物体姿态。原点不能替代 XYZ 方向，任意相机视角下也不能只凭屏幕上的顺逆时针猜实物旋转。

## 当前行为

- 新版启动器使用独立 `Desktop-AssetLibrary` 目录，校验实际托管程序集哈希。后端要求新客户端修订，拒绝旧相机客户端静默显示旧内容。
- U7 资产库 1.1.0 包含六个简化资产；底座组合工具、旋转方向、接触环、螺丝，滑入组合支架、路径方向与终点。默认从工具握持端朝作用端看为顺时针拧紧。
- 显示 XYZ 轴，提供相对已确认作用轴的 XYZ 角度偏移和示意反转。只调整模型朝向，不改写已重建位置；姿态单独保存。
- 拍照找位置前展示底座和白色支架两张官方外观图，并提示同时入镜。允许支架放在桌上；底座被已装支架挡住时如实返回不可见。VLM 框先显示，再用 SAM3.1＋Cutie 分割跟踪。高亮与同一帧照片配对；晚到或错误身份结果不覆盖新画面。
- 识别出的支架额外显示二维代理模型，不冒充三维姿态／锚点，不覆盖用户设好的空间操作位置。
- 拍照参考只让 VLM 判断最终可见安装状态，使用另一张已安装官方图；不请求 GPU。完成时明确弹窗，未安装则提示继续安装，不改变教程进度。
- 与模块二共用五种画幅中心裁剪。默认 4:3 保留旧相机签名；切换画幅关闭当前会话，分别使用对应标定。GPU 不可用时保留识别框，不伪造掩码。

## 实机复测顺序

1. 关闭旧 EXE，运行新交付目录的 `启动教学系统.cmd`，进入 U7 空间指导。
2. 选择原来已标定的相机和 4:3；仅在固定参照未移动时沿用作用点。查看螺丝／工具／旋转提示与 XYZ；若需绕轴调朝向，进入空间锚点配置的 XYZ 姿态。
3. 保持灰色底座和桌面白色支架同时出镜。点拍照找位置，阅读两张外观提示后拍摄；依次查看框、高亮、支架代理模型，再缓慢移动镜头检查跟踪。安装后底座被遮挡是正常情况。
4. 支架尚在桌上时拍照参考，应提示未完成；实际装上后拍清连接再检查，应明确提示安装完成。不要用照片结论代替人工确认机械紧固。
5. 点击停止部件跟踪回到空间动画。切换画幅会重新连接，不能复用其他画幅的标定。
