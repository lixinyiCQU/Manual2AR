# U7 演示交互优化（2026-11-16）

本轮沿用已审核的 U7、现有状态引擎及 AR 资产，优化目标是让用户清楚看到：现场支持什么结论、还缺哪些核实、接下来做哪一步。开箱、首次打印、进料、退料入口保留。

## 如何演示

关闭旧前端和旧后端，使用 `Manual2AR-Data/builds/dev/Manual2AR-Windows/` 内的“启动后端.cmd”和“启动教学系统.cmd”。进入操作指导中的 U7 入口，默认选历史照片演示。

1. 输入“安装料盘支架”，选择底座已装照片，点击“评估现场并生成计划”。
2. 先查看现场结果和官方两步进度，再点击“核实人工项目”，在一个窗口核对底座方向与紧固条件。
3. 确认后直接展示滑入支架动画；可点击照片调整示意位置，也可主动重播。
4. 换为已装支架照片，点击核验，再确认方向，直到显示完成。核验未通过时调整后重验，不要求重新播放动画。

也可试“安装支架底座”“滑入料盘支架”“安装料盘底座及滑入料盘支架”。只安装底座的目标在底座通过后结束；新会话中看不到底座固定处时不会直接放行。

## 修复与行为变化

- 生成计划后隐藏提问输入区，扩大结果区；展示简短现场结论、官方细步骤和下一步，不把判据名称写成已成立的结论。新结果同步排版并回到顶部，避免沿用旧滚动位置。
- 主按钮随阶段改变，重播独立；先展示视觉结果再由用户打开集中人工核实窗口。
- 相机启动只取景，拍摄后冻结；取景不能提交旧照片。相机初始化、关闭及重新打开增加代际保护，未准备好裁剪组件时不允许捕获首帧。
- 切图先清旧画面和叠加；照片加载有超时及重试，请求处理中也可返回。旧请求不能改变新窗口的进度或忙碌状态。
- 每张真实照片检查本次目标及必要前置的全部视觉条件，明确反证会使旧前置失效。普通遮挡保留同会话已经核实的事实，沿用原规则。
- 闲置30分钟的会话在新建任务时回收；正在核验的会话不被回收。记录保存失败仍不推进进度。

后端新增可选 `demo_flow` 展示字段，包含阶段、目标、现场摘要、下一步和细步骤状态。原 `execution`、照片哈希、修订、任务身份及人工条件契约继续负责放行，展示字段不授权完成。

## 参考思想与范围

本轮借鉴 CheckManual 的资料与现场对齐、SayCan 的相关性与可执行性区分、Inner Monologue 的反馈更新，以及 KnowNo 的必要求助思想，未复现其学习算法或统计保证。来源链接见 [演示说明](../baseline/U7_DEMO.md)。

默认历史照片状态是明确编写的演示预设，不计入研究结果。真实模式仍有整图观察、框选裁剪放大和局部复核，没有新增像素级分割。AR 是照片平面示意，需人工调整位置；没有新增自动三维配准。

真实 VLM、实体相机及装配后的 AR 精度仍需现场验收。播放动画不代表完成；人工确认不能绕过缺失或未通过的视觉条件。
