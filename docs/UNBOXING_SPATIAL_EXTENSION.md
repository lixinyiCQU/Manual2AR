本地查看 `Spatial_Test_2.mp4`（38.6 秒，1890×1128，30 FPS）与这些反馈一致：
镜头角度变化后标签继续指向支架区域；约 20–25 秒取景变化／遮挡期间提示隐藏，随后恢复。
这能说明基础空间链路有实机运行证据，不能替代独立测量点的精度验收。

输入 SHA256：`ad755e44fa073e29cacc57299d131bb167f7eab4ebf101fb878e8b1faf12f705`。
视频仅在本地解码与抽帧，没有上传到 VLM 或其他平台。
手工确认的相机区域为 `(228,303,792,594)`；5 Hz 重采样的 193 个样本中，178 次检测到标记，
15 次未检测到。录屏画面变化估计约 8.50 次／秒；这不是硬件相机 FPS，也不是测得的三维精度。
报告与抽帧保存在 `paths.runtime/spatial-test-2-20261103/`。

当前移动点只是短路径上的方向提示，并不是完整部件的移动动画。这一短板保留为后续的

| U4 | 移除减震／保护泡棉 | 工具头、热床、导轨泡棉分别选择；仅高亮实际存在的泡棉，不编造取出路径 | 上项及 `18aaff3a3224135f9d359b07` |
| U5 | 锁紧热床螺丝 | 三颗螺丝独立定位；先摆好热床再设点；只作工具参照 | `661ff0e405da259e12e68b65`、`a835b0d73f70ea468d7d5bed` |

## 怎么打开和试用

1. 关闭旧前端，双击交付目录的 `启动空间演示.cmd`。启动脚本仍将前端同步到 Windows 本地运行。
2. 顶部第一排选 U4／U5／U6／U7，第二排只显示当前章节的动作，避免十个动作挤在一排。
3. 先点“模拟回放”，浏览 U4 的四颗限制器螺丝、扎带、左移、泡棉，以及 U5 的三颗螺丝。
   模拟场景是几何测试场景，不表示真实设备已安装或检查通过。
4. 也可以从原开箱教程进入 U4 或 U5，再点“进入空间指导”；官方 13 章与任意浏览继续保留。
5. 实机新动作需要在“位置设置”中分别建立位置；相机和镜头设置未变时可沿用已保存标定。
   旧 U7 位置不需因软件升级重做，但纸张、打印机和相关安装区域必须保持原有相对关系。

**已经开箱的机器不需要装回运输限制器、扎带或泡棉来做演示。** 不存在的包装件可直接
阅读官方参考图并继续浏览。若只想试新交互，使用模拟回放即可。
热床底部位置不易看到时，先按官方说明摆好热床、相机与固定参照，再设点；再次移动热床
后必须重新设置受影响位置。不要为了这轮软件测试反复拆装已完成的设备。

## 部件移动与旧位置的处理

固定在机架／桌边的标记，并不意味着工具头和热床也固定。
新增动作 `toolhead.slide` 被用户标记为已操作后，程序会暂停工具头扎带、左移与泡棉的
相关位置提示，要求重新设点。它记录的是用户声明的操作，不冒充摄像头检测到了移动。
失效状态存于运行目录 `profiles/rig-validity/`，重启后仍保留；重新设点并确认后清除对应失效状态。
移动前的取景和旧候选不能再次保存为有效位置。

另外修复了旧逻辑中的一处隐含授权：如果用户选择不沿用旧位置，只新设了一个位置，
只会启用新确认的那个位置，不会因此自动启用所有未经确认的其他旧位置。
这些处理不清空相机标定，也不删除旧坐标；旧 U7 主位置格式保持兼容。

## 测试与边界

269 项 Python 回归通过，其中空间及扩展接口 27 项。
Windows Unity 实际 Play 覆盖四场景、U4/U5 教程入口、两级章节导航、四颗限制器螺丝、
扎带与泡棉表现、三颗热床螺丝、人工确认与返回原教程。Windows Player 已编译。
新动作没有做完实物空间精度、动作方向双人审核或安装效果验收。

这次交付的是更完整的 Windows 有标记开箱软件原型，不是已经验收的完整移动 AR 系统。
未实现的部分继续包括：自动三维目标初始化、分割部件替身、真实手部动作、精密工具贴合、
无标记世界跟踪以及 iPhone 端验收。

源码主要位于：

- `resources/tasks/bambu_a1_mini/unboxing/spatial/v1/actions.json`：来源绑定、章节、动作、作用点及检查方式。

- `apps/backend/.../guidance/spatial/service.py`：位置授权、移动失效、章级核验与人工确认边界。
- Unity `Guidance/Spatial/`：章节／动作导航、作用点选择与已有的空间表现。
- `tests/backend/guidance/test_unboxing_extension.py`：新增回归。

开发前的源码和用户位置快照在项目外
`Manual2AR-Data/archives/pre-unboxing-extension-20261103/`，用于本轮回退和复核。
