# A1 mini 开箱 AR 指引

在 Windows 客户端进入 **操作指导 → 打印机开箱**，选择 **外挂料盘** 或 **AMS lite**。在步骤总览点 **开始开箱 AR 指引**。从某章图文页进入时，会接着该章的当前小步骤。

- **演示动作**。点击“播放动作示意”，或点照片里的操作位置放置动画。可以使用官方参考图、自己拍的照片，缺少配图时也可在空白画布上播放。工具转动、移动路径和高亮圈均为教学示意，方向应与官方图、机器实际朝向一起对照。
- **核实现场**。点“启动相机”，对准目标后拍摄，再主动提交评估。结果会说明能看清什么、需要补拍什么。有人工项时，在一个窗口看完并按实际情况确认。播放、浏览、官方图片和“跳过选配章节”都不会产生现场通过记录。
- **接着看或返回**。“下一步”按所选版本的动作与章节顺序浏览。AMS lite 用户可跳过选配的外挂机架。单机 U7 若要指导滑入支架，需先在本轮开箱 AR 核实底座。结束页分别统计浏览与完成记录。

## 两个版本的覆盖

每个版本有 13 章。下表的数量是该章可播放的动作数，同一动作可在两个版本或附录重复使用。

| 章 | 外挂料盘版 | AMS lite 版 |
|---|---|---|
| U1 | 开箱提醒，取出打印机后可参考 Y 轴导轨润滑（1） | 同左（1） |
| U2 | 拆顶部纸壳、逐件取配件、取出打印机（3） | 另含取出 AMS lite（4） |
| U3 | 按本版本的官方清单核对配件（图文） | 按套装清单核对配件（图文） |
| U4 | 拆 Z 轴运输限制器、剪扎带、移工具头、去泡棉（4） | 同左（4） |
| U5 | 调整热床位置、拧紧底部三颗螺丝（2） | 同左（2） |
| U6 | 滑入吐料组件、固定、检查与热床的相对位置（3） | 同左（3） |
| U7 | 安装底座、滑入支架（2） | 可选安装（2） |
| U8 | 检查摄像头膜与屏幕膜，按实际层数处理（2） | 同左（2） |
| U9 | 按外挂示意安装 PTFE 管和料盘（2） | 底座、螺丝、转轴、摆位和四根管路（8） |

## 资产、Prompt 与数据契约

- **动作目录**位于 `resources/tasks/bambu_a1_mini/unboxing/ar/v1/catalog.json`。先按版本、章节和官方子步骤取动作，再按动作 ID 取目标、图文来源、可见条件、人工项和动画 ID。方向向量以照片左上角为原点，显式用于示意。
- **动画资产**位于 `resources/visuals/v1/unboxing.catalog.json`。40 个展示配置引用 21 个网格，包括 15 个新增网格和 6 个已有 U7 资产。每个展示绑定具体网格、动画片段、图层、时长和官方引用。可编辑配方见 `resources/visuals/v1/recipes/unboxing.json`。重新生成可执行 `python -m tools.assets.build_library --unboxing --blender <Blender可执行文件> --output <独立生成目录>`。
- **API** 沿用 `POST /api/guidance/runs` 与 `/browse`。开箱回复中的 `photo_ar` 给出当前动作和资产库标识。会话下的 `POST ar-illustration` 返回可重播的摆放与投影，`POST ar-photo` 提交本次照片，`POST ar-manual` 提交当前全部人工项。请求绑定会话路径、版本、章节、小步骤、动作及修订号；照片另带原始字节哈希与递增帧号。
- **视觉 Prompt** 由 `apps/backend/src/manual2ar/modules/guidance/unboxing_ar.py` 中的 `action_prompt` 按动作生成。现场照片在前，官方参考图在后。模型只回答该动作的可见条件；程序检查返回的动作、照片及结果，决定要求补拍、操作、人工核实或显示已核实。U7 使用原审核过的视觉和人工条件，并保留同会话遮挡处理。
- **位置与结果**。开箱演示使用照片平面的手动位置。原单机 U4–U7 的标记空间指导入口仍可使用。新增步骤的模型属于教学用简化模型。要评估自动三维对准精度和每步视觉准确率，还需要标定及独立标注的现场样本。

## 2026 年 11 月 18 日工程试验

| 试验 | 观察结果 |
|---|---|
| 正式 API，两条完整路线 | 单机 28/28、AMS lite 38/38 个动作位置返回了对应的动画配置，播放前后修订号和任务状态相同。使用受控图像、模型结果和人工输入后，66/66 个位置到达已核实。64 次旧版本操作和 23 次过早人工确认被拒绝。 |
| Windows Unity 交互 | 从开箱总览进入 U2，在官方图上看到了纸壳操作示意。AMS 路线跳过选配 U7 后进入 U8，U7 完成标记保持为空；在 U9 切到第 4 根 PTFE 管后成功渲染动画，返回图文保留同一会话。 |
| 真实模型，历史现场照片 | 最终版两次提交均成功。“取出打印机”的照片能看到机器在箱外，系统停在待人工核实取机手法；“AMS 第 4 根管”的照片没有拍到 AMS 和五通组件，系统要求补拍。调整官方 PNG 参考图的传输格式前，已用同两张照片做过一轮，计两轮、两张不同照片。 |

本机实验目录为 `Manual2AR-Data/runs/dev/unboxing-ar-20261118/`。受控遍历的逐动作结果在 `coverage/`，最终真实模型的请求、哈希及结论在 `real-photo-final/`。Blender 与 FBX 源文件在 `Manual2AR-Data/assets/unboxing-ar-v1/`。本轮没有逐项拆装一台新机或 AMS 套装，视觉准确率和实体对准误差仍待测量。
