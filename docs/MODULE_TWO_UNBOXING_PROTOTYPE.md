# 模块二：整合版开箱指导原型

日期：2026-11-03。开发基线快照：`654c9f3`。本轮新增开发保持未提交。

## 打开和测试

1. 关闭旧前端。在 Windows 交付目录双击 `启动后端.cmd`，保留其窗口；若后端已经启动则无需重复。
2. 双击 `启动教学系统.cmd`，从欢迎页进入 **Bambu Lab A1 mini → 操作指导 → 打印机开箱**。
3. 选择 **外挂料盘／单机**，从总览任意选择章节。13 个章节、原有分步骤和全部官方参考图保持原样。
4. U4—U7 有“进入空间指导”和“指导单元”。默认进入当前官方分步骤对应的动作，也可自行选择本章动作。
5. 初次试用先点“模拟回放”。它演示方向、工具位置、多个螺丝与泡棉作用点，不代表机器已安装。
6. 实机点“启动摄像头”。原有相机标定可以沿用；旧位置是否沿用仍由你确认。新作用点按界面设置。
7. 可以播放、暂停、重新播放、标记“我已操作”，也可以直接返回图文。返回时跟随你最后查看的官方章节／分步骤；不会自动判定安装通过。
8. 在步骤总览中查看学习记录及官方来源。返回任务列表、教学首页后，模块一和模块三仍可进入。

AMS lite 开箱继续提供完整官方图文；本轮的精细空间动作只用于单机版本，不把单机位置套给 AMS。
已经开箱的机器无需装回扎带、运输限制器或泡棉做测试。

## 教学页面布局

正式章节采用左侧说明、右侧大图；配件枚举按条目展示。没有参考图的章节使用完整阅读区，不重复展示任务大纲。
多张参考图可切换；单张图隐藏无用的上一图／下一图按钮，点击图片可放大。
需要照片建议时，点击页面上方“拍照参考（可选）”，打开独立拍摄面板：左侧为大预览，右侧为拍摄指导、反馈与拍照按钮。
摄像头选择与画幅比例收在“镜头设置”中；右上角“返回教学”关闭面板并释放摄像头，保留已有照片和反馈供再次查看。
本轮只调整呈现与阅读，不修改官方任务数据、Prompt、导航政策或核验规则。

### 教学内容的阅读层

六个任务变体的 57 个页面（含分步骤）新增独立的阅读结构：操作指导编号排列；注意事项使用琥珀色提示卡；
通电等步骤的操作前要求放在动作之前；适用版本独立提示；背景与版本补充可展开。
标题、分区标题和正文使用不同字号与样式，段落之间保留约一行的间距。
中英文混排按实际宽度逐字／词排版，保留型号和单位的组合，不依赖 Unity 将连续中文当作长单词的换行结果。

整理后的文本保存于 `resources/modules/guidance_lessons.v1.json`；每个显示区块绑定原始文本字段、字符范围、哈希及引用。
后端 `guidance/lesson.py` 验证内容来源并返回 `presentation.lesson`，Unity 的 `PrinterGuidanceLesson.cs` 负责分类呈现，
`LessonReadableText.cs` 负责排版。原始 Wiki、procedure.json、图像和核验 Prompt 保持原样。
项目内部的实现解释被转为用户可理解的提醒；这些是基于来源的教学整理，不冒充逐字引文。
修改来源后必须重新审核阅读层，不能沿用旧的分类结果。
本轮更新后共 285 项 Python 回归通过；新增检查覆盖 57 个页面的来源、操作／注意事项分离，以及通电前要求的显示顺序。

## 三种辅助功能怎样区分

| 控件 | 帮用户做什么 | 需要什么 | 结果范围 |
| --- | --- | --- | --- |
| 拍照找位置 | 找到当前动作目标；显示框和可用的分割轮廓 | 摄像头与现有 VLM 配置；无需预先设置空间作用点 | 固定照片上的二维候选，不是三维定位或安装判断 |
| 播放示意 | 在已设置的位置显示方向、工具参照或高亮 | 相机标定、固定标记与双视图作用点；也可用模拟回放 | 有标记空间指导；并非部件实体动画或实际动作检测 |
| 拍照参考 | 按原章级 Prompt 检查最后可见安装结果 | 当前实机照片与现有 VLM 配置 | 仅该章节的建议；不确认其中每个微动作或工具操作 |

“拍照找位置”只在点击时上传当前照片，不上传参考图，不持续调用 VLM。
其 Prompt 绑定当前动作、官方操作、目标部件、当前所选螺丝／位置；与原章级检查 Prompt 分开。
模型无法区分某一颗螺丝、目标已移除或被遮挡时应返回未找到／不确定，不编造位置。
可见轮廓使用共享的 seeded GrabCut 实现，不要求 GPU；无可靠轮廓时仍只显示候选框。
画面固定且明确标注“不是三维定位或安装核验”，点击“返回实时”恢复空间指导。

U5 锁紧热床螺丝维持人工确认。图像不能证明螺丝松紧或扭矩；“找位置”不改变这一边界。
GPU 上的 SAM3.1／Cutie 继续服务既有模块；本轮未把它们加入实时空间位姿计算，也未改服务协议。

## 对 Guided Reality 的采用

参考本地《Guided Reality》论文第 4—6 页的“按步选择表现、找到目标、帮助理解动作、用户自主导航”思想，
并参考其冻结取景身份的设计。官方 Wiki 决定本项目的章节和操作，模型不自由生成开箱流程。
运动提示增加有方向的移动箭头与起终点，工具和高亮仍使用本项目独立的程序化几何。

作者公开 [Unity 实验仓库](https://github.com/AdaZhao1211/Guided-Reality-Unity) 面向 Quest 3／Unity 6，
当前实现与本项目 Unity 2022.3／Windows 不同。前期固定提交审阅记录继续有效；本轮没有复制其 FBX、
音频、Unity 源码或私有部署脚本，也没有安装 Meta SDK。未实现完整分割部件替身、手势模型或原生移动 AR。

## 数据与代码职责

- `guidance/experience.py`：依据 citation 将空间动作映射到官方分步骤；为教程附加能力和独立学习记录。
- `guidance/tutorial.py`：仍拥有章节浏览、人工标记和原有核验；本轮不修改其核验语义。
- `guidance/spatial/service.py`：仍拥有标定、位置与会话；新空间会话可绑定 `tutorial_run_id`。
- `guidance/spatial/localization.py`：可选的拍照定位与共享 CPU 分割，不写入三维位置、教程通过结果。
- Unity `PrinterGuidanceController`：三模块中的开箱入口、官方图文、指导单元选择、返回与总览记录。
- Unity `Guidance/Spatial/`：采集、空间提示、播放与固定照片预览；不导入模块一／模块三 Controller。

动作发现通过 run 响应的 `spatial_guidance` 字段，前端不再靠 U4／U5／U6／U7 的硬编码编号决定是否展示入口。
U4 的 `U4-S3` 对应左移和取泡棉；U7 的 `U7-S2` 直接进入向下滑入支架。
在空间页跨章浏览后，返回图文只执行正常导航；操作标记和核验记录不会由此变化。

## iPhone／iPad 接入边界

实际增加了 `ISpatialFrameSource` 采集接口与 `CaptureSnapshot` 契约，Windows 采集通过该接口运行。
`GET /api/guidance/spatial/capabilities` 可查询启用能力：`desktop_rgb`／`synthetic`；`arkit` 为预留。

每份可选快照包含：契约版本、提供方、帧编号、RGB SHA256、尺寸、取景时的应用单调时钟、
upright/unmirrored 像素域。原生 AR 适配器还必须提供参考空间 ID、同帧 3×3 内参和 4×4 相机到世界变换。
矩阵统一行优先、公制、右手坐标；相机 X 向右、Y 向下、Z 向前。ARKit 的原生坐标必须由适配器显式转换。
契约会拒绝反射、非刚体矩阵、NaN、错帧或尺寸不匹配。原生请求目前明确返回未启用，不会套用 Windows 几何。

未来需要分别实现原生相机／同帧位姿提供方、空间放置提供方及世界渲染，并完成 Apple 构建签名和真机测试。
这些接口不等于 iPhone／iPad 已可运行；本轮没有引入 ARKit SDK、Mac/Xcode 依赖或未经测试的 iOS 包。

新增／兼容 API：

```text
GET  /api/guidance/spatial/capabilities
POST /api/guidance/spatial/sessions          # 可选 tutorial_run_id；旧独立演示仍兼容
POST /api/guidance/spatial/sessions/{id}/frames  # 可选 snapshot；旧客户端仍兼容
POST /api/guidance/spatial/sessions/{id}/locate  # 当前 action_id / target_id / client_frame_id
GET  /api/guidance/runs/{id}                 # spatial_guidance 与独立学习记录
GET  /api/guidance/runs/{id}/report           # 同一份教程与空间学习报告
```

## 记录与验证

记录保存在配置的项目外运行目录。空间会话日志带教程身份；定位只保存用户主动请求的照片、Prompt、结果和掩码。
播放、操作标记、拍照定位、章级拍照建议分别记录。模拟与实机分开，不把动画结束或用户点击记作 AI 通过。
run 响应最多保留最近 100 条空间事件，完整事件保留于教程 `events.jsonl`；不无界保存相机视频。
取消／结束教程后，旧空间请求不得再写入该教程；退出关闭相机与空间会话。

整合原型初版整套 Python 回归 280 项通过；新增 11 项覆盖官方分步骤映射、变体隔离、记录幂等、取消后迟到回复、
RGB／空间快照一致性和拍照定位与核验的隔离。Windows Unity 四场景 Play、返回路径、动作匹配、照片预览、
播放与原模块回归另有实际运行截图与日志；使用受控模型，不代表真实 VLM／GPU 或新增实物空间精度验收。

当前仍需你在现场验证：新动作的作用点是否正确、官方方向是否易理解、拍照定位对遮挡／小螺丝的效果。
当前交付名称为“Windows 摄像头版开箱指导原型”，不将其宣称为完整移动 AR V2 验收版。
