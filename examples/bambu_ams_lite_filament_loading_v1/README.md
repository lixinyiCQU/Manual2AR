# AMS Lite filament loading profile v1

This profile combines paper Figures 3 and 4 as one dual-state demo:

- `not_inserted`: a loose filament tip is outside the feeder inlet; guide it upward.
- `loaded`: filament entry into the feeder and continuation inside the PTFE tube are
  both directly visible in the current frame.

The two files in `references/` are runtime exemplars and must be disclosed as such.
They are not part of an independent evaluation set. The second supplied image for
each state is retained for initial held-out scene validation.
