# Manual2AR 说明书任务目录

## 交互原则

系统不把整本说明书强行串成一条流程。用户先选择设备说明书，再选择当前要完成的任务。系统只在该任务的状态图中定位当前状态：

`选择设备 → 选择任务 → 扫描当前状态 → 定位并高亮下一对象 → 记录操作前画面 → 用户操作 → 记录操作后画面 → 验证或纠错`

## AMS Lite 快速指南

### 任务 A：首次机械组装

1. 将 AMS Lite 主体装到支架。
2. 使用 4 颗 BT3-8 螺丝固定。
3. 将 4 根料盘轴滑入对应位置。
4. 检查轴端颜色与主体标记相同：黄色对黄色，绿色对绿色。

### 任务 B：连接 A1 mini

1. 将 AMS Lite 放在 A1 mini 右侧，建议间距约 50 mm。
2. 将四根 PTFE 管接到工具头集线器。
3. 短管连接 AMS 1 号、2 号口。
4. 长管连接 AMS 3 号、4 号口。
5. 插入黑色数据线。
6. 连接 A1 mini 的 4 针接口。
7. 复核所有管路无明显折弯、脱落或跨槽。

### 任务 C：安装并上料一卷耗材

当前可运行演示固定为 1 号槽橙色 PLA。

1. 确认设备空闲，1 号槽空置。
2. 将橙色料盘装到 1 号轴并推紧。
3. 确认耗材从料盘下方朝 1 号送料口展开。
4. 将耗材头平直插入 1 号送料口。
5. 不按黄色释放按钮，等待送料器自动拉料。
6. 从斜上方确认 1 号 PTFE 管中可见橙色耗材，外部路径无明显折弯或缠绕。

黄色释放按钮只用于耗材卡住时分离驱动电机，不是正常上料动作。

### 快速指南未覆盖的任务

正常退料、卡料恢复、部件维护和故障码处理需要另行导入官方维护文档，不能从快速指南中臆造步骤。

## A1 mini 快速指南

### 任务 A：首次开箱与机械装配

1. 解锁 Z 轴固定件。
2. 剪断工具头扎带并移除泡棉。
3. 锁紧热床底部 3 颗运输固定螺丝。
4. 安装废料导向或接料组件。
5. 仅在使用外置料卷时安装右侧料盘支架底座与支架。

### 任务 B：开机、联网与校准

1. 确认 Y 轴运动范围内无障碍物。
2. 接通电源并开机。
3. 连接 Wi-Fi。
4. 使用 Bambu Handy 绑定设备。
5. 执行首次校准。

### 任务 C：外置料卷上料

该任务只适用于不使用 AMS Lite 的情况。

1. 将最短 PTFE 管接到工具头进料口。
2. 将外置料卷装到右侧支架。
3. 将耗材送入 PTFE 管自由端。
4. 复核料卷、管路和工具头连接。

### 任务 D：首次打印

1. 从存储卡选择模型。
2. 使用 AMS Lite 时启用 AMS 配置；使用外置料卷时不要套用 AMS 槽位状态。
3. 建议启用热床调平。
4. 按需启用延时摄影。
5. 启动打印并观察首层。

### 快速指南未覆盖的任务

详细退料、喷嘴维护、堵料恢复、故障码诊断和打印质量排错需要另行导入相应官方文档。
