# U7：安装料盘支架 — 当前实机场景测试

本轮沿用 U4 的图像配准、模型库和播放组件，仅扩展 U7 数据与拍摄／设点引导，保持未提交。
用于单机外挂料盘；不替代 AMS lite 安装指导。

## 入口与新增效果

关闭旧前端和旧后端，运行交付目录的 `启动后端.cmd`，然后运行 `启动教学系统.cmd`。
进入 **操作指导 → 打印机开箱 → 外挂料盘／单机 → U7 → 进入空间指导**。

| 分步骤 | 本轮显示 | 不表示什么 |
| --- | --- | --- |
| 安装料盘支架底座 | 两颗螺丝分别设点，金色内六角模型，拧紧动画 | 不测量扭矩，不自动判断松紧；动画圈数不是安装要求 |
| 从上向下滑入料盘支架 | 蓝色箭头沿底座导向边从上向下移动 | 不是完整支架模型，不估计隐藏卡扣、滑入距离或自动判定装好 |

使用“步骤”下拉菜单切换动作，“位置”下拉菜单切换螺丝。点击“启动摄像头”，有有效位置时自动循环示意。
不再提供模拟回放、播放、暂停或重新播放按钮；位置丢失时隐藏提示，恢复后自动继续。
已经装好的料盘支架可以保留原状，优先测试可见位置与箭头方向，不必为了演示拆卸。

## 针对你照片中的准备

照片中定位纸放在打印机前方，这个位置可以继续用于测试：用胶带贴牢纸张，保持打印机与桌面不动。
固定参照不一定必须贴在打印机外壳上；本轮求解要求的是标记与操作区域之间不发生相对移动。
移动摄像头时，标记四角和要指导的底座区域需同时入镜。保持当前 USB 摄像头与固定 4:3 画幅，不中途切换镜头／分辨率。

截图中显示“请先采集棋盘并计算相机标定”，说明此摄像头配置尚无可用标定。必须先做下面一次准备：

1. 点击“打印标定纸”，按原比例打印，确认定位标记黑色方块边长为 8 cm。
2. 让棋盘完整入镜，在不同位置、距离和倾角采集至少 12 张。每张换一下视角，不重复拍同一摆放。
3. 点击“计算标定”。成功后收起棋盘，把定位标记重新贴牢在照片中的桌面位置。
4. 等待系统识别到标记，再设置当前动作的位置。相机标定通常只做一次；移动标记或相关部件后重设作用点。

不要直接从截图中的标记反推出螺丝的深度，也不要将图片坐标当成已确认的三维位置。

## 先测试滑入箭头

这一步无需把工具停在螺丝处，更适合先跑通链路。

1. 选择“从上向下滑入料盘支架”，把相机转到能看清底座竖直导向边的位置。
2. 点击“空间锚点配置”，再点“设置起终点”，固定第一视角。
3. 点 **1：导向边上端**，再点 **2：同一导向边下端**。两点必须是实物上看得见、可重复辨认的角点，不点空中。
4. 点击“换角度再取景”。保持打印机和定位纸不动，把相机横移约 15–25 cm，再固定第二视角。
5. 在第二视角仍按相同顺序选择同一对实物角点。画面会显示点名，避免上下或顺序混淆。
6. 检查选点并点击“确认保存位置”，返回指导后自动显示示意。
7. 蓝色箭头应沿刚才的导向边由上向下移动。移动相机后仍应留在同一区域；遮住标记应隐藏提示并暂停。

已安装的支架可能挡住内部插槽。此时只用外露导向边测试方向；若连导向边也看不到，请换角度，不编造卡槽终点。
界面标签使用“支架滑入方向”，避免把示意点说成隐藏插槽的精确位置。

## 再测试底座螺丝

1. 选择“安装料盘支架底座”，选“螺丝 1”。摄像头应面对底座安装面，拍清当前螺丝。
2. 把内六角扳手插在该螺丝上，先不拧动，保持工具、打印机与标记都不动。
3. 按同样的双视角流程设点：**1：扳手长杆外端；2：当前螺丝中心**。只有摄像头移动，两视角必须选同一对点。
4. 保存后自动循环。工具尖端应对准螺丝，旋转方向是拧紧，与 U4 的拧下示意相反。
5. 在下拉菜单切换“螺丝 2”，为另一颗螺丝单独设置。两个编号是你设点时分配的标签，不要求 VLM 猜哪颗是 1 或 2。

工具随相机移动或手持漂移，会让双视角对应点不一致。无法保持同一位置时先取消；不要在空气中随便点一个“手柄方向”。
如果螺丝被支架遮挡，先换拍摄角度；这次不要求拆开已安装的设备。
旧作用点可以保留；若先前选的两点没有表达真实工具轴线，请重新设置该颗螺丝。

## “拍照找位置”与“拍照参考”

“拍照找位置”只在点击后上传当前照片；有有效作用点时，额外发送同一照片的局部放大图，不发送历史参考图。
Prompt 附带当前 U7 分步骤的定位约束和用户位置提示；提示本身不算视觉确认或安装证据：
底座螺丝不与运输限制器、导轨或底脚螺丝混淆；滑入任务只找可见底座插槽／导向区域，不把水平托臂当作插槽。
被已安装支架遮挡、无法区分所选螺丝时，要求模型返回未找到／不确定。它不写入三维作用点。

“拍照参考”仍是原官方章节最后可见安装状态的建议；不验证每次转动，不验证扭矩，不强制阻止下一步。
本轮不新增自动 VLM 调用，不更改已有 GPU 服务配置，不把示意播放当作操作完成。

照片回复在右侧“拍照反馈”区域滚动查看，画面下方只显示简短状态。后端配置过旧会提示重启，不再静默显示旧线条。

右侧已移除重复的首次标定介绍；需要设点时才保留相应操作提示。操作说明可单独滚动，官方图片有更大显示空间。
点击官方图片可按原始比例放大查看，点击“关闭图片”或遮罩空白返回；不会提交照片、修改位置或中断实时定位。

## 实测时记录这四项即可

- 蓝色箭头是否沿实物导向边向下，标签是否清楚。
- 两颗螺丝的工具尖端是否分别落在你指定的位置。
- 相机横移后是否保持贴合；遮住再露出标记时是否正确暂停、恢复。
- 切换螺丝／分步骤时，是否清除了上一步模型。

后端扩展是动作数据里的 `visual_guidance`、`capture_guidance`、`authoring_points`、`localization_context`，
继续复用 `guidance/spatial/visuals.py` 和统一的 `asset/projection` 契约。
Unity 使用现有模型渲染器，新增独立的 `SpatialPickLabels.cs` 显示设点名称，不引入 U7 专属 Controller 或核验分支。
