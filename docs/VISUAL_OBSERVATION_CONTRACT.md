# 严格视觉观察契约 v1

2026-11-11。新增实验开关 `visual_observation_contract`（严格视觉观察契约），可单独启用或与现场驱动执行规划组合；全部预设现在含12项。默认关闭保留对照，关闭时旧的自由文本核验仍为旧方法。新契约缺少规范时不能降级到旧核验。所有身份/人工/视觉边界门控始终有效。

## 流程及边界

官方证据 → 原任务及条件 → 动作绑定 → 观察规范编译/一次格式修复 → 语义覆盖审核 → 冻结候选 → 操作者审核规范 → 当前现场事实采集 → 程序执行规则 → 会话验收。

编译器输出仍是候选，不是已人工审核的Ground Truth。语义审核不保证语义正确，必须保留人工评价。不能以更弱的“部件存在”取代“接口连接”，不能因契约无法表达就删除原要求、自动转成人工或复制旧人工U7。

- `compile*/observations/observation_specs.json`：对象特征、搜索区域、查询谓词，状态为candidate_requires_operator_review。
- `compile*/observations/acceptance_rules.json`：独立的期望值、来源类型、出处和理由。
- `compile*/observations/coverage-review.*`：规范是否覆盖原条件的语义审核；不通过则候选unsupported。
- 运行时每次检查保存query、现场/参考图角色与哈希、原始findings、程序evaluated结果。多帧逐帧观察再按已有规则聚合。

整个compile目录参与候选冻结，改规范或规则后不可批准/继续执行。旧候选不改写。

## 第一版可执行词表

| 谓词 | 查询 | 规则期望 | 证据 |
| --- | --- | --- | --- |
| feature_presence | 特定区域内指定特征 | present/absent | 目标已辨认、区域完整可观察、实例框 |
| instance_enumeration | 枚举区域内特定类别实例 | 0..30整数 | 区域框、可见实例框列表；程序计数，拒绝高度重叠重复实例 |
| relative_position_2d | 两个有身份特征的位置 | left/right/above/below | 按顺序的两个框；程序比较中心；仅upright图像平面 |
| marking_readout | 读取指定标识原文 | 精确文本 | 标识框、原样字符；不模糊补全 |
| unsupported | 当前无法执行的规范 | 不执行 | 说明缺少特征、模板或证据接口 |

轴线/角度容差、三维朝向、接触/插入到位和隐藏锁止没有通用执行器，必须unsupported。接口特征若能完整归约到现有原语可提出候选，但须审核其是否真正证明原条件；不能以单一特征存在冒充连接。未定义的朝向标准会阻止接入，而不是让VLM猜长短边。后续新增谓词必须实现对应的参数校验、观察结果类型、判定器和测试后才能执行。

## 现场观察

模型只接收当前节点的特征定义/查询、现场图及明确标为identity_reference的身份参考图；不接收expected、原自由文本完成条件、用户声明、任务通过标签。参考帮助辨认，不作为现场证据。

返回：source_sha256、每个spec_id、observability、coverage、现场区域框、实例框/有序特征框/原样字符及短证据解释。没有status=completed字段，额外验收结论被严格schema拒绝。

observability：observable/occluded/out_of_frame/unresolved_identity/insufficient_detail。coverage：complete/partial/unknown。没有完整区域证据不能从空实例推出不存在；证据框须在报告区域内，坐标0..1000，步骤与源图身份继承原检查。

系统根据规则产生completed/not_completed/uncertain；返回的confidence_origin=deterministic_rule_not_model_accuracy，数值不是感知精度或模型概率。观察模型误认对象或虚报可见性仍可能产生错误，必须用标注样例评价，不能把规则确定性当识别可靠性。

多项规范全部满足才满足原观察点；任何明确反证则不满足，否则未知。人工条件保持独立，视觉失败不能人工绕过。纯人工不调用视觉事实模型。片段前置条件没有对应结构化规范时保持未知，不回退自由文本或无条件放行。

## 场景对齐与前端

启用本开关的现场驱动执行规划中，部件位置识别与任务状态判断分开：PartsObservation只定位部件，Findings采集事实，规则计算每个条件的状态；不请求TaskScene模型自行判断安装完成。新模式不以用户完成声明放行；原话仍保存在任务input，当前结构化评估不另外抽取user_claims。

任务预览新增特征、规范及期望值，要求操作者审核。unsupported候选可预览其缺口，“确认进入AR”禁用。模型输出审查通过不等于操作者已审核，用户批准才允许创建AR会话，但也不授权任务完成。

## 评价与范围

单元与受控端到端测试检查：查询不含期望/自然语言条件、遮挡不放行、数量和二维关系由程序计算、跨照片/重复证据/额外结论拒绝、规范篡改拒绝、未定义朝向不降级、人工门控保留。

受控provider只证明接口行为，不证明编译规范忠实。实际实验必须另标注特征和规则是否覆盖原要求、是否编造参照；记录错误放行率、未知率、补拍恢复率、重复一致性及人工审核成本。

论文参照：SOMA（对象角色）、FOON/PROC2PDDL（动作及状态）、kPAM/ReKep（功能特征及几何关系）。本实现是轻量观察/验收契约，不是完整本体、PDDL求解器、三维约束优化器或论文复现。未增加任意Python执行、机器人控制或三维定位能力。
