# BOOK-RIG 01 Proxy Equipment Manual

Document ID: BR01-MANUAL-v1  
Purpose: pre-laboratory testing of manual-scene alignment only  
Not an instruction for operating any real equipment

## Components

- **A - Fixed marker:** remains beside the book and must not move.
- **B - Access cover:** the front cover of the book.
- **C - Control disk:** a paper disk with an arrow that can point LEFT or UP.
- **D - Module A:** the yellow removable card.
- **E - Module holder:** the outlined area on the left page.
- **F - Target slot:** the green pocket on the right page.

## Initial state

- Access cover is closed.
- Control disk points LEFT.
- Yellow module A is in the left-page holder.
- The green target slot is empty.

## Procedure

### Step 1 - Open the access cover

Open the cover until both marked pages are visible.

Expected result: control disk, module holder, module A, and target slot are
visible in the same scene.

### Step 2 - Set the control disk

Rotate the control disk clockwise until the arrow points UP.

Expected result: the arrow tip overlaps the UP mark.

Wrong state: arrow points LEFT, RIGHT, DOWN, or is between marks.

### Step 3 - Remove module A

Remove the yellow module A from the outlined holder.

Expected result: the holder is empty and module A is visible outside it.

Wrong state: another object is removed or module A remains partly inside.

### Step 4 - Insert module A

Place yellow module A fully inside the green target slot.

Expected result: the center of module A lies inside the target slot and no
large part of the module crosses the pocket boundary.

Wrong state: wrong object, wrong slot, or partial insertion.

### Step 5 - Close the access cover

Close the front cover completely.

Precondition: Step 4 has already been verified.

Expected result: the cover is closed and the fixed marker remains visible.

## Uncertainty and recovery

- If the target component is hidden, blurred, or outside the image, request
  another view and do not advance.
- If a prerequisite state is not satisfied, return to the first unmet step.
- Never infer a successful hidden state solely from the user's hand motion.
