# 公共 UI 契约

本契约面向当前 Windows uGUI 教学端。已有后端任务、核验、坐标、帧身份和完成条件保持原义；后端不返回像素位置或任意 UI 脚本。

## 页面与区域

导航为“资料库 → 设备教学首页 → 可选任务目录 → 业务工作区”。模块一直接进入部件认知；模块二、三使用 `AppTaskMenu`。图文查看、相机设置和确认框作为覆盖层，不增加业务层级。

`Common/AppWorkspace` 定义两种模板：

| 模板 | 主内容 | 辅助区域 |
| --- | --- | --- |
| Visual | 配对相机画面、分割或空间提示 | 部件知识、拍摄指导或结构化结果 |
| Reading | 官方操作指导、注意事项、补充说明 | 官方参考图片 |

固定区域为标题、右侧导航、工具栏、主内容、辅助侧栏、左下相关操作、右下任务操作。标题、相机、按钮和侧栏不得由业务 API 指定坐标。章节控件和三维提示可以在各自区域内部安排；不改变画面／掩码的配对规则。

没有侧栏的阅读章节可扩展正文；空间指导可收起工具栏、底部操作区，把空间让给画面。空间标定栏仅显式打开时显示。模块一的部件选择和模块二的分步骤选择允许滚动或下拉，不依赖固定条目数量。

## 样式与组件

| 公共组件 | 职责 |
| --- | --- |
| `AppTheme` | 字体、颜色、圆角、图标、标题 32、正文 26、辅助字 22、操作按钮高 64（1920×1080 参考单位） |
| `AppActionBar` | 同组按钮等高、等宽；隐藏操作后自动重排 |
| `AppCameraBar` | 启动、切换／镜头设置及画幅；相机会话仍由模块管理 |
| `AppContent` / `AppReadableText` | 可滚动正文、段落间距、按可用宽度中文断行，保护型号和单位 |
| `AppMediaEmptyState` | 没有图像时的提示，收到图像后隐藏 |
| `AppDialog` / `AppModalBackdrop` | 小／标准／大三种弹窗、背景遮挡和模糊、最上层 Escape 关闭、恢复原焦点 |

按钮的图标由调用方显式指定。公共主题只在创建时设置，不定时遍历按钮，不根据中文文案猜图标，不覆盖业务主动设置的强调样式。长正文应滚动，不能靠缩小到不可读字号解决。短按钮标签可在 22 至 26 的范围内适配。

操作指导、注意事项与补充说明保持分组；来源原文不混入相机运行状态。场景内文字继续遵循 `GUIDANCE_DISPLAY_CONTRACT.md`，不把普通 UI 正文断行器用于三维文字网格。

## 状态与操作

- 处理进度：等待、识别、分割、完成或请求失败。
- 定位状态：当前框／掩码／空间提示可用、恢复中或失效。
- 任务状态：未完成、待确认、视觉核验通过或人工确认。

三者分别来自原模块的状态，不合并为单个“成功”。识别成功不等于安装完成；核验失败不清空仍有效的跟踪；旧帧标注不能套用新相机图。模块三只显示用户结果，不直接呈现原始 VLM 回复。

核验失败在辅助栏保留依据和下一步建议；需要用户作决定时才显示确认弹窗。关闭弹窗、浏览教材、播放动画均不算通过。U7 底座通过后仍需用户确认才进入支架安装；第二步保持手动拍照识别。

底部左侧放相关功能，右侧放任务操作。相机启动、画幅、动画设置属于工具栏；识别／检查、确认完成和上一步／下一步属于任务操作。不得为了统一按钮位置绕过后端的前置条件或允许状态。

## 扩展与验证

新增页面选择模板，再向对应区域放置内容和操作；优先使用上述公共组件。不复制一份完整 BuildUI，不新增按任务 ID 分支的公共页面框架，不把某个模块的业务规则移入 Common。

`tests/unity/UiGalleryValidation.cs` 是仅在隔离 Editor 工程中运行的组件预览。覆盖 1280×720、1920×1080、1600×1000 下的两种模板、长文本、错误反馈、按钮隐藏重排和区域边界，输出独立 PNG。它与完整四场景流程一同由以下入口执行，不添加用户菜单：

```bash
.venv/bin/python -B -m tools.build.validate_desktop --unity <Unity.exe> --project <仓库外隔离工程> --build
```

这些是模板尺寸和受控流程验证，不代表所有 Windows DPI、真实摄像头、GPU、手机竖屏或原生 AR 已验收。移动设备安全区域与原生 AR 面板需要单独适配。
