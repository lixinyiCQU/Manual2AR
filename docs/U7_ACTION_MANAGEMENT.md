# U7 动作管理与模型朝向

进入 U7 空间指导、建立作用点后，点击「动作管理」。

- 组件下拉菜单由当前 presentation 的实例生成：底座步骤包含工具、转向箭头、接触环和螺丝；支架步骤包含支架模型、终点环和移动箭头。
- 每个组件可显示／隐藏、自动循环／静态起始姿态，并单独调整模型局部 XYZ 旋转、工作坐标偏移、大小、播放倍率和旋转方向覆盖。
- 「整体移动与旋转」设置移动轴、正负方向、距离、周期和螺丝旋转方向。顺／逆时针均从工具柄朝作用端观察，不按屏幕左右判断。
- 修改后点击「应用并保存」，回到相机画面查看效果。静态模式回到动画起始姿态，不是暂停后继续当前相位。

## 方向与路径分离

支架模型的安装姿态相对于打印机工作坐标定义，沿打印机 −X 伸出、局部竖直方向为 +Z；下滑路径默认 −Z。改变移动方向或距离不再翻转模型。没有打印机坐标时仍保留两点模式，使用显式模型局部方向修正。

资产 Layer 的 `rotation_degrees` 定义两点模式朝向；可选的 `printer_rotation_degrees` 定义打印机工作坐标下的固定姿态。路径始终单独由两作用点或整体运动参数生成，不从模型旋转推断。

转向箭头 Layer 标记 `reverse_with_rotation`：反转旋转方向时，渲染采样器同时翻转箭头形状的切向方向，再执行旋转。工具自身不作该形状翻转。RGB 和未来原生 AR 渲染共用同一个采样器。渲染器接收连续的循环位置，组件倍率跨整体循环边界连续累积，避免慢速组件每轮被截断。

## 数据与边界

`MotionParameters.components` 按组件 ID 保存 `visible`、`playing`、`rotation_degrees`、`offset_mm`、`scale`、`speed`、`rotation_sign`。未配置组件继承默认值；旋转方向 0 表示继承整体。参数存入原有 `profiles/motions/<rig>.json`，按动作独立，两个底座螺丝共用动作参数、保留各自作用点。

后端拒绝不属于本动作的组件 ID、重复 ID、非有限数和越界参数。参数只影响教学显示，不改变标定、作用点、跟踪掩码或安装核验结果。旧参数文件无需迁移，新增组件列表默认为空。模型局部旋转与工作坐标偏移在 UI 中分别标明；没有工作坐标时偏移采用原两点基底。
