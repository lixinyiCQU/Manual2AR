# U4：解锁 Z 轴限制器和工具头 — 本地视觉指导

本轮在 `3beb4ad` 的模块二 UI 里补充模型提示，保持未提交。
保留现有官方章节、参考图、自由导航和可选拍照建议；未实现首次使用全自动三维定位。

## 如何测试

1. 关闭旧前端；后端有旧进程时先关闭，再双击交付目录的 `启动后端.cmd`。
2. 双击 `启动教学系统.cmd`，进入 **操作指导 → 打印机开箱 → 外挂料盘／单机**。
3. 从步骤总览进入 **U4：解锁 Z 轴限制器和工具头**，点击 **进入空间指导**。
4. 启动摄像头；已有有效位置时自动循环示意。
5. 通过步骤下拉菜单切换动作，系统自动循环示意：

| 单元 | 显示 | 用户应关注什么 |
| --- | --- | --- |
| 拆除 Z 轴限制器螺丝 | 所选螺丝的位置圈、金色 L 形内六角工具、拧下示意 | 可切换四颗螺丝；工具尖端落在当前所选位置，动画不是要求的拧动角度或圈数 |
| 剪断并取下扎带 | 扎带作用点和剪刀开合示意 | 先对照官方图辨认运输扎带，不把线束作为扎带；模型不自动判断可安全剪切 |
| 工具头稍向左移 | 蓝色立体箭头沿已设置的起终点移动 | 方向取自打印机实际导轨上的作用点，不把屏幕左侧当作设备左侧；箭头不是工具头实体替身 |
| 取下减震及保护泡棉 | 泡棉位置的半透明光圈 | 可切换工具头／热床／导轨泡棉；光圈标记作用点，不代表完整泡棉分割边界 |

6. 实机测试点 **启动摄像头**。沿用原相机标定；只有确认标记及对应部件没有移动，才沿用原作用点。尚未设置的位置仍需原来的双视角设点。
7. 遮住标记，提示应隐藏，示意暂停；恢复标记后自动继续。切换单元不应保留上一单元工具。工具头实际移动后，标记“我已操作”会使相关旧作用点失效，之后重新设置。

已开箱设备不需要为演示重新装回运输扎带、限制器或泡棉。没有对应包装件时，浏览官方图文即可。
播放、用户操作标记和章级拍照建议继续独立记录；动画结束不算安装通过。

## 架构与数据

- `resources/.../spatial/v1/actions.json`：U4 的资源选择与动作意图。官方原始过程、参考图和核验契约保持原样。
- `guidance/spatial/visuals.py`：根据当前已确认的起终点，生成模型放置矩阵和当前图像的投影参数。
- `manual2ar_contracts/spatial.py`：可选的 `asset` 与 `projection` 字段。仍使用原图帧编号、SHA256、动作及目标身份。
- `SpatialAssetGeometry.cs`：独立的模型库与示意动画；工具工作端是局部原点，模型轴线和尺度有明确约定。
- `SpatialAssetGraphic.cs`：把模型网格投影到当前匹配 JPEG 的视图，使用相同内参、畸变及相机位姿；不另开渲染相机。
- `SpatialGuidanceController.cs`：接收同帧数据，控制显示、播放和退出清理；不拥有模型几何或业务核验规则。

模型在米制标记坐标系里放置，前端使用逐顶点透视与镜头畸变投影，因此不同视角下的方向和缩放会随相机变化。
它仍是 Windows 摄像头版的注册式图像叠加，非原生 ARKit 世界渲染；工具没有真实场景深度遮挡。
工具绕轴的滚转参考来自固定标记，不是模型自动估计的物体表面法线。工具尺寸是教学示意，不是实物测量值。
实时分割跟踪服务不参与模型作用点求解，原有模块一、模块三视觉服务配置保持不变。
以后可以沿用模型、动作、作用点约定，替换空间提供方与渲染器接入 iPhone／iPad。
