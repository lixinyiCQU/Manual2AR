# Manual2AR 明日演示方案（2026-08-18）

## 明天只证明什么

证明一个受约束的单设备闭环已经成立：针对 Bambu Lab A1 mini 与 AMS Lite 的“1 号槽安装橙色料盘并上料”任务，系统能够给出操作前视觉指引，接收操作前后照片，用千问 VLM 读取可见状态，再由确定性的安全门决定是否进入下一步。

明天不宣称已经解决跨设备迁移、所有四槽组合、隐藏机械状态、逐帧 VLM 视频理解或生产级 AR 稳定性。

## 5 至 8 分钟演示顺序

### 1. 先讲问题和边界（40 秒）

- 设备：A1 mini 加 AMS Lite。
- 当前任务：橙色料盘安装到 1 号槽并完成上料。
- 用户交互：手机给取景和操作提示，记录操作前画面；用户放下手机双手操作；再按指定角度记录操作后画面。

### 2. 展示预定义知识（50 秒）

打开 `examples/bambu_a1_mini_ams_lite_v1/procedure.json`，只解释两个状态和五个可观测检查点：

- 料盘确实位于 1 号槽。
- 耗材头朝向正确且尚未插入。
- 耗材进入 1 号送料口。
- PTFE 管内出现橙色耗材。
- 外部路径连续且无明显错误绕线。

强调：这些状态由“说明书内容加人工审核”预定义；VLM 不负责临场发明成功标准。

### 3. 展示操作前高亮（50 秒）

展示安装料盘的 SAM 2.1 淡绿色 mask，以及上料步骤因 mask 质量不足而自动退回透明框的样例。

要讲清楚：

- 人工审核框或 VLM 框提供“找哪里”的种子。
- SAM 2.1 把粗框细化成物体轮廓。
- 连续跟踪让高亮随相机画面移动。
- mask 质量不够时不伪装准确，退回透明框。

### 4. 实机跑完整闭环（2 至 4 分钟）

1. App 连接后端，确认界面显示 `qwen3.8-max` 与 `sam2.1`。
2. 记录操作前画面。
3. 按提示放下手机完成操作。
4. 从指定角度记录操作后画面。
5. 展示模型的可见证据、置信度和组件位置。
6. 展示 `safe_to_advance` 决定继续、纠错或补拍。

如果现场机器正在打印或操作状态无法复原，立即跳到离线仪表板，不要临时制造不受控状态。

### 5. 展示失败保护与当前数据（1 分钟）

- 千问 sanity pair：正确看到打印板从空变为出现橙色成品，置信度 0.95，安全门放行。
- MiniCPM 正例虽然输出 `completed`，但细检查不全或不确定，因此安全门不放行。
- 无变化负例中 MiniCPM 出现误判或 JSON 错误，因此当前选千问作为 VLM 基线。

这比只展示一次“成功识别”更有说服力，因为它同时说明系统如何拒绝不可靠输出。

## 现场打开顺序

1. 双击 `start_manual2ar_full.command`，粘贴百炼 API Key。
2. 双击 `demo_preflight.command`，必须没有红色失败项。
3. 打开 `demo_tomorrow/index.html` 作为讲解首页与兜底。
4. 解锁 iPhone，确认与 Mac 同一 Wi-Fi；需要重装时运行 `install_manual2ar_iphone.command`。
5. 先自己完整彩排一次，再让师兄看第二次。

## 现场失败切换规则

- iPhone 连接失败：直接展示离线仪表板和真实照片，不在师兄面前排查网络。
- 千问超时：展示已保存的千问 JSON，并说明云端延迟是工程问题，不把缓存结果冒充实时结果。
- SAM2 失败：展示透明框 fallback，说明分割只影响高亮精细度，不改变 VLM 状态判断。
- 机器不可操作：用已经采集的 before、after_001、after_003 讲完整数据流。
