# 使用与交付

本说明对应当前 Windows 摄像头原型。系统入口为资料库 → A1 mini 教学首页 → 部件认知／操作指导／打印状态检查。仅已安装的官方离线资料参与教学；资料上传与自动编译入口尚未实现。

## 本机运行

在当前工作树执行 `bash run.sh start`，检查 `http://127.0.0.1:8010/health`。Windows 使用完整解压目录中的“启动教学系统.cmd”；启动器把程序同步到本地磁盘再打开，更新前关闭旧窗口。Unity 编辑器使用 2022.3.34f1，入口是 `Welcome` 场景。

`configs/app.local.json` 管理后端地址、相机、模型和资料路径；修改公开配置后执行 `bash run.sh sync`。配置中的相对路径以配置文件上两级目录为基准。GPU 令牌另存 `configs/inference.connection.local.json`，不放进前端或聊天。

官方 Wiki 原始档案、运行记录、缓存和构建均在仓库外。移动代码不等于删除已保存标定。不要手动清空 `paths.runtime/guidance-spatial/profiles/`。

## 三个模块

- 部件认知：启动相机 → 识别 → 查看高亮和部件说明；点击部件名称查看官方离线 Wiki。
- 操作指导：选择任务与版本 → 总览／图文章节 → 按说明操作。图文完成由用户确认；空间指导的完成标记来自对应视觉核验。
- 打印状态检查：当前实现打印板异物和残料检查；其他任务仅占位。清理后复检，打印头默认遮挡可进入专用人工确认。检查照片通过不等于整台设备、附着力或打印成品质量合格。

相机画幅统一使用旋转／镜像校正后的中心裁切。改变画幅后重新识别；空间标定也必须对应当前相机和画幅。

## U7 空间指导

1. 进入“安装料盘支架”的空间指导，启动相机，让固定定位标记及操作位置同时入镜。
2. 初次使用先打开“空间锚点配置”，打印系统标定纸，按 100% 比例打印。按界面采集至少 12 个不同角度的棋盘视图，再计算相机标定。
3. 设置作用点时保持打印机与标记固定，从两个有明显平移的视角选择同一组真实点。两颗底座螺丝分别设点；不要用想象偏移代替第二颗螺丝位置。
4. 需要按打印机轴播放动作时设置工作坐标 O／+X／+Z；详细方法见 [打印机工作坐标](PRINTER_WORK_COORDINATES.md)。它与“操作起终点”是不同配置。
5. 有有效缓存时，在操作位置点击“开始本步”，确认本次场景未改变。阅读官方图文并关闭后，底座步骤自动识别底座；有效分割就绪后播放工具动画。
6. 安装好底座后点“检查安装”。通过后由用户确认进入支架步骤；没有通过则留在本步。相机标定、分割成功和动画播放都不能解锁下一步。
7. 支架步骤先摆好灰色底座和白色支架，手动点击“识别部件”；不会自动拍照。高亮两部件并播放滑入示意，完成后再次“检查安装”。

顶部入口集中管理摄像头、动画、空间锚点、官方图文和返回。图例在有指导内容时显示，名称固定在左上角；场景只保留目标旁的短操作指令，部件颜色与图例一致。官方图文可重新打开并点击图片放大。

“动画管理”中可对组件设置显隐、循环／静态、模型旋转、坐标偏移、尺寸和速度；整体动作支持轴、方向、距离、周期及转角。顺／逆时针从工具柄朝作用端观察，不按屏幕左右判断。动作参数仅供教学，不是扭矩、要求圈数或电机控制命令。

## 视觉故障与恢复

GPU 不可达时自动尝试本机 CPU 分割／跟踪；VLM 不可用时不能伪装成离线语义识别。标记丢失会隐藏无法定位的三维动画；二维跟踪不是三维位姿估计。重新识别成功后替换旧跟踪，失败保留仍可用的原跟踪；安装核验失败不主动清空跟踪。

取消会撤销尚未执行的排队任务，并在 VLM 和分割调用前检查。已发出的网络请求无法保证撤回，迟到结果会被丢弃。实际跟踪丢失必须重新识别，不能把静止旧掩码套到新画面上。

坐标重建失败时，按诊断编号在运行目录查看主动采集的两张图、点击和重投影信息；重新选择同样的真实点。不要仅为让检查通过而降低几何阈值。
