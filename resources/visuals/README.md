# Manual2AR 教学视觉资产

`v1/style.json`：统一样式、坐标、类别与预算。
`v1/recipes/u7.json`：可编辑建模配方及 U7 场景组合。
`v1/catalog.json`：带版本、哈希、动作和引用的运行目录。
`v1/meshes/`：由 Blender 配方生成、供 Windows／未来 AR 共用的米制网格。

大型 `.blend`、FBX 和预览留在项目外 `Manual2AR-Data/assets/u7-v1/`。生成方式和扩展规范见 `docs/VISUAL_ASSET_LIBRARY.md`。
本阶段只有 U7 使用新库；其余章节保留原有表现。手势和情境组件仅定义类别，尚未制作。
