# U7 自动空间配置

适用：Windows RGB 摄像头、A1 mini 外挂料盘 U7。扫描坐标板建立教学 XYZ，拍两个视角自动设置两颗螺丝和可见导向边；无需逐点点击。保留原手动配置与动画微调。它不控制打印机，不从二维分割推断真实深度。

## 从旧配置重新开始

1. 关闭旧版窗口，用交付目录的 **启动教学系统.cmd** 打开。进入模块二 → 开箱 → U7 → AR 指导，启动原来标定过的镜头并保持相同画幅。
2. 点击 **空间锚点配置 → 备份并重新配置 → 备份并清除**。清除这台打印机的旧作用点、工作坐标、模型朝向和动作微调；相机标定及教学进度保留。不要手动删除整个 `profiles` 目录。
3. 打印 **A1-mini工作坐标板.pdf**，使用实际大小／100%，关闭适应纸张。量一下黑色正方形边长 80 mm、校验线 100 mm。贴在硬平板上，平放桌面、正面朝上。
4. 将板的 **+X 与打印机 X 横梁正向平行**（从打印机正面看向右）；**+Y 指向机器背面**；**+Z 垂直桌面向上**。固定板与打印机。标记中心就是教学原点，无需与旧原点重合。
5. 让整块黑色标记、灰色底座和两颗螺丝入镜。点击 **开始自动配置 → 确认方向，扫描坐标板**。这个确认不能省略：软件知道纸张的坐标，不能独立证明你将它与机器对齐。
6. 右侧点击 **拍第一视角**。等待局部定位完成后，保持机器、底座和板不动，将相机横移约 15–25 cm，仍看清标记和同一灰色底座，点击 **拍第二视角**。
7. 第二张画面上的黄色十字应对准两颗螺丝／可见导向边。核对后点击 **核对无误，保存**；位置不准则重新拍摄，或用手动配置后备入口。
8. 返回实时画面，在操作位置点击 **开始本步**。原有部件高亮与三维工具动画继续使用；动画管理仍可调整方向、距离、速度和组件偏移。
9. 底座安装经过独立的视觉核验、用户确认后才能进入滑入支架步骤。若本次也定位出了导向边，滑入动画位置已经配置；没有辨认到外轮廓边时，使用两颗已重建螺丝之间的底座参考点播放上下方向示意，明确标注不代表隐藏插槽或实际行程；无需重复清空螺丝配置。需要精确调整时仍可手动设点。

若未标定相机，先进入 **手动配置 / 相机标定 → 相机及工作坐标设置**，使用旧的棋盘采集和计算标定流程。相机内参、纸张坐标、目标作用点是三种不同数据；本功能减少后两项的手工选点，不代替相机内参标定。

定位纸与打印机发生相对移动时重新配置；仅移动相机无需重设。平放板的摆放约定不能用于随意贴在竖直立柱上的标记。

## 结构与契约

- `automatic_guidance.py`：四种可见功能点及五类指导配方的严格契约。VLM 只输出语义和二维点，允许不可见，不输出可执行代码或三维矩阵。
- `automatic_vision.py`：第一轮找灰色底座 ROI，第二轮放大裁剪定位功能点，保存裁剪到原图的映射和源照片。每视角两次 VLM 请求，不请求分割 GPU。
- `automatic.py`：坐标板确认、几何三角化、候选与保存、配置冲突检查和旧配置备份。复用原重建的 3 px 重投影、5°–100°视线角、正深度约束，并检查螺丝上下关系和导向边方向。
- `automatic.json`：U7 两个已审核配方，引用原 `actions.json` 和视觉资产。螺丝作用点绑定 `main/second`，滑入终点绑定可见导向边。工具轴与旋转约定来自教学模板；示意距离、周期、转角不是 Wiki 测量值。
- `SpatialAutomaticSetup.cs`：两次取景向导和精确源帧预览；候选确认后使用既有动画采样器。原生 AR 以后可以复用米制配置和渲染适配器，不在此实现 ARKit。

新增接口位于 `/api/guidance/spatial`：

| 方法与路径 | 作用 |
| --- | --- |
| `GET /workboard.pdf` | 80 mm 标记、XYZ 和打印校验线 |
| `POST /sessions/{id}/automatic/reference` | 明确确认摆放后，以当前标记建立工作坐标 |
| `POST /sessions/{id}/automatic/reset` | 备份旧位置配置，保留相机标定 |
| `POST /sessions/{id}/automatic/views` | 在已提交的原始帧中定位功能点 |
| `POST /sessions/{id}/automatic/candidates` | 两视角几何解析与预览，不保存作用点 |
| `POST /sessions/{id}/automatic/confirm` | 明确确认后保存候选 |

自动配置只扩展 U7 的初始化方式，不改变部件分割、CPU 回退、核验 Prompt、人工紧固确认和分步骤前置关系。高亮、移动、工具、手势、情境共用配方类别；本次实际制作和自动绑定的是 U7 既有工具／移动组合，没有新增手势骨骼或计时器资产。

## 保存、手动调整与恢复

工作原点 `MachineFrame` 新增 `placement_method=printed_reference`、`reference_profile_id` 和单张标记证据；旧手动双视角格式继续使用两张证据。作用点仍保存为原米制目标格式，新增自动配方、机器坐标与原图身份。

已有效的手动作用点不会被自动候选覆盖；手工动作微调不被自动重置。选择“备份并重新配置”才清空这些数据。预览后若配置被修改、目标失效、坐标改变或结果过期，保存被拒绝。失败不覆盖旧配置，也不改变安装核验结果。

备份在运行目录 `guidance-spatial/profile-backups/<backup-id>/`，含原 JSON 及 SHA256 清单；诊断照片、关键点叠图和重建指标在 `guidance-spatial/runs/<session>/automatic-*`，不进入 Git。需要恢复时关闭空间会话，核对 manifest 后将备份 JSON 放回对应的 `profiles/<group>/<rig-id>.json`；重新打开并明确确认场景未变化。不能恢复相对位置已经改变的旧作用点。

自动测试使用合成图、受控 VLM 和已知几何，不能证明真实小螺丝识别率与实机贴合精度。现场测试应先核对十字与 XYZ，再观察动画，避免将动画效果当作测量或验收。

## 滑入动画位置不足时

旧配置只有两颗有效螺丝时，系统在运行时生成“底座参考点 · 滑入方向示意”，不改写旧文件、不声称恢复隐藏插槽；源螺丝失效、坐标 ID 不符或几何不合理时不会生成。已手动设置的滑入位置优先，旧位置失效时需要补充定位。右栏分别显示高亮状态、动画定位状态及示意位置说明；缺少定位时提供“补充动画定位”。定位板丢失时提示露出标记，不能只因二维跟踪继续而显示没有可靠位姿的三维动画。
